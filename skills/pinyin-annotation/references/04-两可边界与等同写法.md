# 参考四：两可边界与等同写法

这一份回答「哪些写法**不算错**、遇到两可时**怎么选**」。教学产出要求**全篇体例一致**。

## 1. 明确两可的写法（两种都对）

| # | 等价写法 | 说明 |
|---|---|---|
| 1 | `wǒ de` ＝ `wǒde` | 单音节词 +「的」可连写（6.1.9.1）；**全篇统一** |
| 2 | `jiǎng de` ＝ `jiǎngde` | 同上（"得"字补语句） |
| 5 | `tiào wǔ` ＝ `tiàowǔ` | 离合词无插入成分（跳舞） |
| 6 | `bāng máng` ＝ `bāngmáng` | 同上（帮忙） |
| 7 | `jiā yóu` ＝ `jiāyóu` | 同上（加油） |

**选择策略**：教学产出一律选**词表写法优先，其次连写**；全篇保持同一选择。

## 2. 明确**不可两可**、必须按规则写的高危点

| 点 | 规则 | 错例 → 正 |
|---|---|---|
| 句末「了」 | 分写 | `…dàole.` ❌ → `…dào le.` |
| 动词后非句末「了」 | 连写 | `mǎi le` ❌ → `mǎile` |
| 成语可分双音节 | 半字线 | `fēngpínglàngjìng` ❌ → `fēngpíng-làngjìng` |
| 成语不可分双音节 | 全连写 | `céngchū-bùqióng` ❌ → `céngchūbùqióng` |
| AABB | 连写 | `fāngfāng miànmiàn` ❌ → `fāngfāngmiànmiàn` |
| ABAB 重叠 | 分写 | `yánjiūyánjiū` ❌ → `yánjiū yánjiū` |
| 数量短语 | 分写 | `liǎnggèrén` ❌ → `liǎng gè rén` |
| 序数「第」 | 连接号 | `dìshísān` ❌ → `dì-shísān` |
| 邻近数约数 | 连接号 | `qībā gè` ❌ → `qī-bā gè` |
| 指示代词+点儿/会儿 | 连写 | `zhè diǎnr` ❌ → `zhèdiǎnr`（对照：+量词/名词分写，`nǎzhāng` ❌ → `nǎ zhāng`） |
| 形容词+点儿/一些 | 分写 | `kuàidiǎnr` ❌ → `kuài diǎnr`（对照：副词「有点儿」连写） |
| 动词+补语 | 双单音节才连写，其余分写 | `zǒujìnlái` ❌ → `zǒu jìnlái`（对照：`dǎsǐ` 连写 ✔） |
| 名词+方位词 | 已成词连写，否则分写 | `tiān shàng` ❌ → `tiānshàng`；`shānshàng` ❌ → `shān shàng` |
| 隔音符号 | 有则必有，无则必无 | `píǎo` ❌ → `pí'ǎo`；`gōng'zuò` ❌ → `gōngzuò` |
| 轻声 | 不标调 | `zhuōzǐ` ❌ → `zhuōzi` |
| 「一/不」教学变调 | 标变调 | `yìtiān` 写成 `yītiān` ❌（教学场合） |

## 3. 三条严重错误红线（违反即整段返工）

1. **每音节切开**：整段没有一个连写——等于没有做分词连写；
2. **全篇连写**：整段没有一个空格——同样等于没有做分词连写；
3. **通篇小写/通篇大写**——等于没有做大小写体系。

这四条在真实教学材料里同样是灾难性错误，输出前必须自检排除。

## 4. 体例一致性的三个「统一」

1. **「的/地/得」**：wǒ de 还是 wǒde——全篇统一；
2. **离合词**：tiàowǔ 还是 tiào wǔ——全篇统一；
3. **方位词**：tiānshàng（固化）连写 vs shān shàng（临时组合）分写不是矛盾——固化为词的连写、临时组合分写，判定看词感与词表。

## 5. 教学口径与 GB/T 正文差异速查

| 项 | GB/T 16159-2012 正文 | 教学口径 |
|---|---|---|
| 「一/不」标调 | 默认原调（yī tiān、bù duì） | **标变调**（yì tiān、bú duì）——教学通例 |
| 离合词 | 无专条（按 6.1.2.3 动宾分写） | 《HSK标准教程》：分开写；无插入成分两可 |
| 句末「了」 | 分写（6.1.2.2） | 同 GB/T：分写 |
| 顿号 | 可用逗号代替 | 教学输出直接写逗号 |
| 标点形制 | 标准文本用全角、6.7 规定拼音句号 `.` | 拼音一律半角 |

遇到任务方给的具体要求（如「按原调标」「必须全连写」），**任务要求优先于本手册默认值**——在动笔前确认口径。
