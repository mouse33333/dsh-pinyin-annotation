# 参考二：分词连写（以词为书写单位）

法源：GB/T 16159-2012 §5 总则、§6.1 分词连写规则；补充《HSK 标准教程》教学口径。

**总原则**（5.1）：拼写普通话基本上**以词为书写单位**。词内连写，词间空格。双音节、三音节表示一个整体概念的结构连写（5.2：quánguó 全国、dǎnxiǎo 胆小、duìbuqǐ 对不起、chīdexiāo 吃得消）；四音节以上按词或语节分写（5.3：wúfèng gāngguān 无缝钢管、huánjìng bǎohù guīhuà 环境保护规划），不能划分的全连写（yánjiūshēngyuàn 研究生院、hóngshízìhuì 红十字会）。

## 1. 词的切分判定（按词类）

### 1.1 名词 + 方位词（6.1.1）

| 规则 | 例 |
|---|---|
| 名词与后面的方位词**分写** | shān shàng（山上）、mén wài（门外）、hé lǐmian（河里面）、huǒchē shàngmian（火车上面）、xuéxiào pángbiān（学校旁边） |
| 名词+方位词**已成词的连写** | tiānshàng（天上）、dìxia（地下）、kōngzhōng（空中）、hǎiwài（海外） |

判别口诀：**能插"的/中间"的是短语，分写**（山（的）上边 → shān shàng）；**读音融合、意义专指的是词，连写**（天上＝天空）。方位词"上面/外面/里面/旁边"自身是词，连写（shàngmian、wàimian、lǐmian、pángbiān）——**「面」教学体例读轻声、写 mian 不标调**（GB/T 例词 huǒchē shàngmian 即如此），写成 shàngmiàn 全调是常见错误；词典注音作 miàn 时以指定词表为准。

### 1.2 动词（6.1.2）

| 规则 | 例 |
|---|---|
| 动词 + 动态助词"着/了/过"**连写** | kànzhe（看着）、tǎolùn bìng tōngguòle（讨论并通过了）、jìnxíngguo（进行过） |
| **句末**"了"兼语气助词**分写** | Zhè běn shū wǒ kàn le.（这本书我看了。）、Huǒchē dào le.（火车到了。） |
| 动词 + 宾语**分写** | kàn xìn（看信）、chī yú（吃鱼）、kāi wánxiào（开玩笑）、jiāoliú jīngyàn（交流经验） |
| 动宾式合成词插入其他成分**分写** | jūle yī gè gōng（鞠了一个躬）、lǐguo sān cì fà（理过三次发） |
| 动词+结果补语：两者都单音节**连写** | gǎohuài（搞坏）、dǎsǐ（打死）、shútòu（熟透）、jiànchéng（建成）、huàwéi（化为）、dàngzuò（当作） |
| 动词+介词性补语（到/在/给等）**分写** | zǒu dào（走到）、zhù zài（住在）、sòng gěi（送给） |
| 动词+补语其余情况**分写** | zǒu jìnlái（走进来）、zhěnglǐ hǎo（整理好）、jiànshè chéng（建设成）、gǎixiě wéi（改写为） |

**"了"四分法**（教学重点）：
1. 动词后、非句末 → 连写：`tōngguòle`、`mǎile`（买了）、`qùguo`（去过）；
2. 句末兼语气 → 分写：`dào le.`、`kàn le.`；
3. **形容词后 → 分写**：`lǜ le`（绿了）、`hǎo le`（好了）——形容词当谓语带"了"表变化，"了"是语气助词，分写；
4. 可能补语中间的"得"（de）连写：`kàndeqǐ`（看得起）、`chīdexiāo`（吃得消，5.2 例）。

**凝固词不拆**：词典收为词条的动补式合成词（看 kànjiàn 见、听 tīngdǒng 懂、收 shōudào 到、找 zhǎodào 到、碰 pèngjiàn 见）是**一个词**，连写；只有"动词+补语"是临时组合（整理 hǎo 好、建设 chéng 成、走 jìnlái 进来）才按 6.1.2.4 分写。判别：查词典——词条里收的连写，没收的分写。

### 1.3 形容词（6.1.3）

| 规则 | 例 |
|---|---|
| 单音节形容词 + 生动前/后附成分**连写** | mēngmēngliàng（蒙蒙亮）、liàngtāngtāng（亮堂堂）、hēigūlōngdōng（黑咕隆咚） |
| 形容词 + "些/一些/点儿/一点儿"**分写** | dà xiē（大些）、dà yìxiē（大一些）、kuài diǎnr（快点儿）、kuài yìdiǎnr（快一点儿） |

注意区分：「有点儿 / 一点儿」作**副词/数量词时自身连写**（yǒudiǎnr、yìdiǎnr），与后面中心语分写。别把「形容词+点儿」（分写，kuài diǎnr）和「有点儿+形容词」（连写的 yǒudiǎnr 开头）搞混。

### 1.4 代词（6.1.4）

| 规则 | 例 |
|---|---|
| 人称/疑问代词与其他词语**分写** | Wǒ ài Zhōngguó.（我爱中国。）、Shéi shuō de?（谁说的?）、Qù nǎlǐ?（去哪里?） |
| "这/那/哪" + 名词或量词**分写** | zhè rén（这人）、nà cì huìyì（那次会议）、nǎ zhāng bàozhǐ（哪张报纸） |
| "这/那/哪" + "点儿/般/边/时/会儿"**连写** | zhèdiǎnr（这点儿）、zhèbān（这般）、zhèbiān（这边）、nàshí（那时）、nàhuìr（那会儿） |
| "各/每/某/本/该"等 + 名词/量词**分写** | gè guó（各国）、měi nián（每年）、mǒu rén（某人）、běn shì（本市） |

人称代词本身连写复数：wǒmen（我们）、tāmen（他们）。

### 1.5 数词和量词（6.1.5）

| 规则 | 例 |
|---|---|
| 十一到九十九的整数**连写** | shíyī（十一）、sānshísān（三十三）、jiǔshíjiǔ（九十九） |
| "百千万亿"与前面个位数连写 | sānbǎi（三百）、qīwàn（七万）；"万/亿"与十位以上数分写：liùshísān yì（六十三亿） |
| 序数"第" + 数词**加连接号** | dì-yī（第一）、dì-shísān（第十三）、dì-èrshíbā（第二十八） |
| "初" + 一~十**连写** | chūyī（初一）、chūshí（初十） |
| 月日数词中间**加连接号** | wǔ-sì（五四）、yī'èr-jiǔ（一二·九） |
| 数词与量词**分写** | liǎng gè rén（两个人）、yī dà wǎn fàn（一大碗饭）、kàn liǎng biàn（看两遍） |
| 数量与约数"多/来/几"**分写** | yībǎi duō gè（一百多个）、shí lái wàn rén（十来万人）、jǐ jiā rén（几家人） |
| "十几/几十"连写 | shíjǐ gè rén（十几个人） |
| 邻近数字并列表约数**加连接号** | sān-wǔ tiān（三五天）、qī-bā gè（七八个）、qiān-bǎicì（千百次） |

### 1.6 副词、介词、连词（6.1.6–6.1.8）——一律分写

| 词类 | 例 |
|---|---|
| 副词与后面的词分写 | hěn hǎo（很好）、dōu lái（都来）、gèng měi（更美）、zuì dà（最大）、bù lái（不来）、fēicháng kuài（非常快） |
| 介词与后面词语分写 | zài qiánmiàn zǒu（在前面走）、xiàng dōngbiān qù（向东边去）、wèi rénmín fúwù（为人民服务）、cóng zuótiān qǐ（从昨天起）、bèi xuǎnwéi dàibiǎo（被选为代表） |
| 连词分写 | gōngrén hé nóngmín（工人和农民）、tóngyì bìng yōnghù（同意并拥护）、bùdàn kuài érqiě hǎo（不但快而且好） |

### 1.7 助词（6.1.9）

| 规则 | 例 |
|---|---|
| 结构助词"的/地/得/之/所"分写；**前面的词是单音节时也可连写** | dàdì de nǚ'ér（大地的女儿）、Zhè shì wǒ de shū. / Zhè shì wǒde shū.（这是我的书。）、mànmàn de zǒu（慢慢地走）、dǎsǎo de gānjìng（打扫得干净）、lěng de fādǒu（冷得发抖） |
| 语气助词分写 | Nǐ zhīdào ma?（你知道吗?）、Kuài qù ba!（快去吧!）、Tā yīdìng huì lái de.（他一定会来的。） |

"的/地/得"全篇体例要统一（wǒ de 与 wǒde 都合规则，但不能混用出两可）。

### 1.8 叹词、拟声词（6.1.10–6.1.11）——与其他词语分写

À! Zhēn měi!（啊! 真美!）、Āiya, wǒ zěnme bù zhīdào ne!（哎呀, 我怎么不知道呢!）、jījīzhāzhā（叽叽喳喳）。

## 2. 重叠式（5.4）

| 形式 | 规则 | 例 |
|---|---|---|
| AA（单音节词重叠） | 连写 | rénrén（人人）、niánnián（年年）、shuoshuo（说说）、dàdà（大大）、gēgè（个个） |
| AABB | **连写** | láiláiwǎngwǎng（来来往往）、shuōshuōxiàoxiào（说说笑笑）、fāngfāngmiànmiàn（方方面面）、qiānqiānwànwàn（千千万万） |
| ABAB（双音节词重叠） | **分写** | yánjiū yánjiū（研究研究）、shāngliang shāngliang（商量商量）、xuěbái xuěbái（雪白雪白）、tōnghóng tōnghóng（通红通红） |
| 红红的（A+的） | 连写后加 de | hónghóng de（红红的） |

## 3. 前附/后附成分（5.5）

单音节前附成分（副、总、非、反、超、老、阿、可、无、半）或后附成分（子、儿、头、性、者、员、家、手、化、们）与其他成分**连写**：

| 例 | |
|---|---|
| zǒnggōngchéngshī（总工程师）、fùbiāotí（副标题）、fēijīnshǔ（非金属）、chāoshēngbō（超声波）、lǎohǔ（老虎）、āyí（阿姨）、wútiáojiàn（无条件）、bàndǎotǐ（半导体） | 前附 |
| zhuōzi（桌子）、jīnr（今儿）、quántou（拳头）、kēxuéxìng（科学性）、chéngwùyuán（乘务员）、yìshùjiā（艺术家）、xiàndàihuà（现代化）、hǎizimen（孩子们） | 后附 |

**例外**：人名场合"老/小/大/阿"+姓**分写**（Xiǎo Liú 小刘、Lǎo Qián 老钱），两截首字母都大写——这是 §6.2.1.3 的人名规则，压过 §5.5。

## 4. 连接号（5.6，半字线 `-`）

并列的词/语素之间或缩略语中可用（部分场合为"规定性要加"）：

| 场合 | 例 |
|---|---|
| 并列语素缩略语 | rén-jī duìhuà（人机对话）、lù-hǎi-kōngjūn（陆海空军）、biànzhèng-wéiwù zhǔyì（辩证唯物主义）、Cháng-Sānjiǎo（长三角） |
| 邻近数字约数 | sān-wǔ tiān、qī-bā gè |
| 序数"第" | dì-yī、dì-shísān |
| 月日 | wǔ-sì（五四） |
| 双姓 | Zhāng-Wáng Shūfāng（张王淑芳） |

**两条细则**（常见双向错误）：

1. **连接号加在"并列单位"的边界，并列单位是词不是字**：先把缩略语还原成原词——若某成分本身是一个多字词，该词**内部不加线**；只有真正并列的单字/单词之间才加。三字并列加两条线（lù-hǎi-kōngjūn 陆海空军：陆、海、空三字并列）；两词缩略只加一条线（如「中医＋西医」缩略为「中」＋「西医」两个单位，一条线）；**不要按字数均分加线**（两词缩略成三字时，是一条线，不是两条）。
2. **大小写跟专名性走**：专名缩略（两地地名缩略 + 铁路/公路类通名、机构缩略名）**每个成分首字母大写**（Jīng-Guǎng Tiělù 京广铁路形）；普通并列缩略（人机、文理类一般语词缩略）**全小写**（rén-jī duìhuà 人机对话形）——加线规则一样，大小写按是否专名分。

**不加连接号的场合**（「方向记反」双向错的另一半）：

| 场合 | 正 | 错 |
|---|---|---|
| 不能分两个双音节的成语 | céngchūbùqióng（层出不穷） | céngchū-bùqióng ❌ |
| 一般词内/普通语素间 | píngfēn（平分）、niánqīng（年轻） | píng-fēn、nián-qīng ❌ |

## 5. 成语和熟语（6.1.12——体例要求最严的一类）

| 结构 | 规则 | 例 |
|---|---|---|
| 四字成语、可分两个双音节 | **中间加半字线** | fēngpíng-làngjìng（风平浪静）、àizēng-fēnmíng（爱憎分明）、shuǐdào-qúchéng（水到渠成）、píngfēn-qiūsè（平分秋色）、guāngmíng-lěiluò（光明磊落）、diānsān-dǎosì（颠三倒四） |
| 四字成语、不能分两个双音节 | **全部连写** | céngchūbùqióng（层出不穷）、bùyìlèhū（不亦乐乎）、zǒng'éryánzhī（总而言之）、àimònéngzhù（爱莫能助）、yīyīdàishuǐ（一衣带水） |
| 非四字熟语 | 内部**按词分写** | bēi hēiguō（背黑锅）、yī bíkǒng chū qìr（一鼻孔出气儿）、bā gānzi dǎ bù zháo（八竿子打不着） |

判断"能不能分两个双音节"看语义结构：风平/浪静（主谓+主谓）、爱憎/分明（并列+形容）、水到/渠成可分；层出不穷（动+补+动+补交错）、不亦乐乎（1+1+1+1 虚词结构）、一衣带水（偏正结构嵌套）不可分。**拿不准时查词典的成语注音**，词典按本条标注。

## 6. 离合词（教学口径：《HSK 标准教程》）

| 场合 | 写法 | 例 |
|---|---|---|
| 有插入成分（了/过/数量补语） | **必分写** | tiào le wǔ（跳了舞）、xǐle yí gè zǎo、jūle yī gè gōng（鞠了一个躬） |
| 无插入成分 | 连写与分写**两可**，全篇一致 | tiàowǔ ＝ tiào wǔ（跳舞）；bāngmáng ＝ bāng máng（帮忙）；jiāyóu ＝ jiā yóu（加油） |

教学产出一律选**词表写法优先，其次连写**；全篇保持同一选择。

## 7. 语段标注的完整流程（对照示例）

原文：`他很喜欢看中国电影。`

1. **分词**：他 / 很 / 喜欢 / 看 / 中国 / 电影
2. **套规则**：代词分写；副词"很"分写；"喜欢"是词连写；动词独立；专名"中国"连写大写；"电影"连写
3. **逐字注音**：他 tā、很 hěn、喜欢 xǐhuan（欢轻声）、看 kàn、中国 Zhōngguó、电影 diànyǐng
4. **组装**：`Tā hěn xǐhuan kàn Zhōngguó diànyǐng.`（句首大写、句号小圆点）

再如：`我的朋友会说一点儿英语。`
→ `Wǒ de péngyou huì shuō yìdiǎnr Yīngyǔ.`
（"我的"取分写体例；péngyou 轻声；"一点儿"连写且「一」标变调 yìdiǎnr；"英语"作专名成分大写）
