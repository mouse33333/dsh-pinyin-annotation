# 参考三：专名拼写、大写、标点、移行

法源：GB/T 16159-2012 §6.2 人名地名、§6.3 大写、§6.4 缩写、§6.6 移行、§6.7 标点。

## 1. 人名（6.2.1）

| 场合 | 规则 | 例 |
|---|---|---|
| 姓和名 | **分写**，姓前名后，首字母**分别大写** | Lǐ Huá（李华）、Wáng Jiànguó（王建国）、Zhāng Sān（张三） |
| 复姓 | **连写** | Dōngfāng Shuò（东方朔）、Zhūgě Kǒngmíng（诸葛孔明） |
| 双姓 | 中间**加连接号**，两姓首字母都大写 | Zhāng-Wáng Shūfāng（张王淑芳） |
| 名 | 双音节名连写 | Jiànguó 不是 Jiàn Guó |
| 人名 + 职务/称呼 | **分写**，职务首字母**小写** | Tián zhǔrèn（田主任）、Wǔ kuàijì（吴会计）、Lǐ xiānsheng（李先生）、Liú lǎoshī（刘老师）、Zhào tóngzhì（赵同志）、Huìfāng āyí（慧芳阿姨） |
| 已专名化的称呼 | 连写、大写 | Kǒngzǐ（孔子）、Bāogōng（包公）、Xīshī（西施）、Mèngchángjūn（孟尝君） |
| "老/小/大/阿"+姓 | **分写**，两截首字母**都大写** | Xiǎo Liú（小刘）、Lǎo Qián（老钱）、Dà Lǐ（大李）、Ā Sān（阿三） |
| 笔名、别名 | 按姓名写法 | Lǔ Xùn（鲁迅）、Méi Lánfāng（梅兰芳） |

## 2. 地名（6.2.2）

| 场合 | 规则 | 例 |
|---|---|---|
| 专名 + 通名 | **分写**，每一部分首字母大写 | Běijīng Shì（北京市）、Héběi Shěng（河北省）、Yālù Jiāng（鸭绿江）、Tài Shān（泰山）、Dòngtíng Hú（洞庭湖）、Táiwān Hǎixiá（台湾海峡） |
| 专名/通名的单音节附加成分 | 与相关部分**连写** | Xīliáo Hé（西辽河）、Jǐngshān Hòujiē（景山后街）、Dōngsì Shítiáo（东四十条） |
| 已专名化的地名 | 不再分专名通名，**各音节连写** | Wángcūn（王村[镇]）、Zhōukǒudiàn（周口店）、Sāntányìnyuè（三潭印月）、Jiǔxiāngqiáo（酒仙桥） |

## 3. 非汉语人名地名（6.2.3）

外国的**汉字译名**照汉字用汉语拼音拼写（不是回拼原语言原文）：

- Lúndūn（伦敦）、Dōngjīng（东京）、Wūlǔmùqí（乌鲁木齐）
- Mǎkèsī（马克思）、Āpèi Āwàngjìnměi（阿沛·阿旺晋美）、Jièchuān Lóngzhījiè（芥川龙之介：姓+名分写）

首字母大写规则同专名；音译词内部按汉字词界连写或分写。

## 4. 专名成分 vs 一般语词（6.3.3）

| 判定 | 例 |
|---|---|
| 专名成分+普通成分连写后**仍是专名** → 首字母大写 | Míngshǐ（明史）、Hànyǔ（汉语）、Yuèyǔ（粤语）、Guǎngdōnghuà（广东话）、Fójiào（佛教）、Tángcháo（唐朝） |
| 已**虚化为一般语词** → 全小写 | guǎnggān（广柑）、jīngjù（京剧）、ējiāo（阿胶）、zhōngshānfú（中山服）、chuānxiōng（川芎） |

**操作化判据**：某地/某朝成分+普通名词，若该词现在指**一类物品/一般概念**（词典按普通词收录、不再特指该地/该朝）→ 全小写（京剧＝一类剧种、广柑＝一类水果）；若仍特指与该专名绑定的**具体事物/领域**（汉语＝特指中文这门语言、明史＝特指那段历史）→ 大写。拿不准查词典：词典立为普通词条的写小写，专名词条的大写。

## 5. 大写规则（6.3）

| 场合 | 例 |
|---|---|
| 句子开头 | Chūntiān lái le.（春天来了。）、Wǒ ài wǒ de jiāxiāng.（我爱我的家乡。） |
| 诗歌每行开头 | Yǒude rén huózhe,（有的人活着，）每行行首大写 |
| 专有名词首字母 | Běijīng（北京）、Chángchéng（长城）、Qīngmíng（清明）、Jǐngpōzú（景颇族） |
| 多部分专名：**每个词**首字母大写 | Guójì Shūdiàn（国际书店）、Hépíng Bīnguǎn（和平宾馆）、Guāngmíng Rìbào（光明日报）、Guójiā Yǔyán Wénzì Gōngzuò Wěiyuánhuì（国家语言文字工作委员会） |
| 带调大写元音也算大写 | Ǎ、Ǒ、Ǔ、Ǚ、Ǜ 与 A、O 同等——**别以为调号盖住就不是大写** |

**大小写底线**：通篇小写或通篇大写都是严重错误。整篇必须有大小写区分。

## 6. 缩写（6.4）——仅了解，语段注音一般不涉及

连写单位缩写取每字首字母大写连写（Běijīng→BJ、ruǎnwò→RW）；分写结构以词为单位取首字母（guójiā biāozhǔn→GB、hànyǔ shuǐpíng kǎoshì→HSK）；可加点（B.J.）。**缩写词不可移行**。

## 7. 标点符号（6.7）

| 规则 | 对 | 错 |
|---|---|---|
| 句号用小圆点 `.` | Chūntiān lái le. | 。❌ |
| 连接号用半字线 `-` | fēngpíng-làngjìng | 全角连字符 ❌ |
| 顿号可用逗号 `,` 代替 | xiān shuā yá, xǐ liǎn | 、❌（教学输出直接写逗号） |
| 问号、感叹号用半角 | ?  ! | ？！❌ |
| **标点后空一格**（或换行） | Nǐ zhīdào ma? 或 hǎo de, wǒ… | 缺空格 ❌ |
| 破折号（插入语） | 单个 `—` | 中文全角双字线 `——` ❌ |
| 中文原文的引号 | 照 GB/T 15834 转为对应半角 | |
| **原文标点逐个照写** | 原文有几个标点（含句中逗号、分号、冒号、行末逗号），拼音一个不丢、一个不加 | 漏写原文逗号/冒号 ❌ |

> 安全规则一句话：**拼音文本里从头到尾只用 `, . : ? ! —` 这几个半角符号，见顿号写逗号，见破折号写 `—`**，任何全角标点都是错。

## 8. 移行（6.6）

| 规则 | 例 |
|---|---|
| 按音节分开，未写完处**加连接号**；音节内部不可拆 | guāngmíng → guāng-míng ✔；gu-āngmíng ❌ |
| 缩写词不可移行 | Wáng J. G. 保持原样 |
| 音节前有隔音符号，移行时**去掉符号加连接号** | Xī'ān → Xī-ān ✔；Xī'-ān ❌ |
| 在连接号处移行：行末保留、**下行开头补加** | chēshuǐ-mǎlóng → 行末 chēshuǐ- / 行首 -mǎlóng |

## 9. 语段组装完整示例

原文：`他慢慢地走进了图书馆。`

```
Tā mànmàn de zǒu jìnle túshūguǎn.
```

拆解：句首 Tā 大写｜mànmàn 连写｜结构助词 de 分写｜zǒu 分写｜jìnle 动词+了连写（非句末）｜túshūguǎn 三音节整体名词连写｜句号 `.`。
